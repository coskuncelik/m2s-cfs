| D25 | 2026-11-04 | Step 04b design of the static RAM file system (D19): a core (`os-ramfs.c`, no OSAL/FreeRTOS) keeps each volume inside one memory area ([header][entries][block table][blocks]); the OSAL glue (`os-impl-filesys.c`) maps OSAL's file, directory and file-system calls onto it under one static mutex. `OS_mkfs`/`OS_initfs` with an address use that memory (cFE's case); without one they take an area of a static pool (256 KiB on the simulator). Every non-fixed file system is a RAM disk, with system mount point `ramfs:<n>`. Fixed maps (`OS_FileSysAddFixedMap`, e.g. `/cf`) are directories of one built-in 32 KiB root volume. Nothing touches the host disk. No `.`/`..` entries; an open file or directory cannot be removed or replaced, and a volume with open handles cannot be stopped. Built-in read-only files (D5) are deferred to the cFE step. All sizes are compile-time settings in `os-freertos.h`. | Plan approved by the user with the recommended answers (caller memory, 256 KiB pool, own core test, defer D5 files). Semantics follow the POSIX implementation's return codes, which the OSAL tests were written against. |
