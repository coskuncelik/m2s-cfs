| D25 | 2026-11-04 | Step 04b design of the static RAM file system (D19): a core (`os-ramfs.c`, no OSAL/FreeRTOS) keeps each volume inside one memory area ([header][entries][block table][blocks]); the OSAL glue (`os-impl-filesys.c`) maps OSAL's file, directory and file-system calls onto it under one static mutex. `OS_mkfs`/`OS_initfs` with an address use that memory (cFE's case); without one they take an area of a static pool (256 KiB on the simulator).
